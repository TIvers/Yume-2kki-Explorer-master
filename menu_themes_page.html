Yume 2kki:Menu Themes

View source
  • View history
Discussion

By exploring and interacting with the dream world, Urotsuki can obtain menu themes (also called menu types), changing the appearance of the menus. The player can choose the theme they wish to use in the tools menu on Urotsuki's computer.

There are currently 113 selectable menu themes in the game. When a new game is started, there are 7 starting menu themes, and more are unlocked by interacting with special NPCs & objects throughout the dream world. Alongside that there are 9 temporary menu themes, which cannot be freely selected on the computer.

Each menu theme is listed below in order according to the computer menu, along with a brief description of where they can be found.

Temporary Menu Themes

These are menu themes that do not get added to the Tools menu in the computer, which persist under certain conditions. Like menu themes, temporary menu themes will be overwritten if a different one is selected.

Icon Location Condition(s) Image In-game
Saturated Eyeball Zone Killing this NPC will instantly replace your current menu theme with the eyeball theme. The NPC dies permanently, so this menu theme will be forever unobtainable if you change your menu theme afterwards.
NES Glitch Tunnel Only available when exploring the NES Glitch Tunnel.
Shop Ruins Can be toggled by interacting with the heart-shaped NPC in the pink 8-bit area, accessible from the bottle in the left table of the hidden chemical storage in Shop Ruins. This menu theme lasts until you use the Eyeball Bomb effect or wake up, and can be re-obtained as much as you want.
Love Lodge Killing the Witch of Hatred will temporarily give you this menu theme. This lasts until you use the Eyeball Bomb effect or wake up, and can be re-obtained as much as you want.
Nerium Lab These themes are available after interacting with each maid in Nerium Lab's first room. Unlike the other themes of this list, they stay toggled after waking up, but still can't be selected in the computer.
Glitch Hell Interact with the musical eyeball-like creature. This is the default RPG Maker menu. It lasts until the Eyeball Bomb effect is used or Urotsuki wakes up, and it can be repeatedly re-obtained. This theme can be brought to the rest of the dream world by setting a Bat warp point in the isolated section of Humanism from Microbiome World, then going to Humanism through the Glitch Hell route and using the Bat effect.
Glitch Hell Interact with a nonsensical, green bug-like creature. This seemingly glitched version of Menu Theme #52 lasts until the Eyeball Bomb effect is used or Urotsuki wakes up, and it can be repeatedly re-obtained. This theme can be brought to the rest of the dream world by setting a Bat warp point in the isolated section of Humanism from Microbiome World, then going to Humanism through the Glitch Hell route and using the Bat effect.
